# 공식 분석 산출물

이 폴더에는 보고서와 후속 분석에서 직접 사용하는 확정 CSV만 보관한다. 원천자료와 중간 산출물은 저장소에 포함하지 않는다.

## 추적 기준

- 대상 기간: 2016–2024년
- 지역 단위: 17개 시도(전국값은 참고용)
- 공식 산출물: 기초 패널, 재정대응지수 패널, 총세출 분모·민감도 패널, 재정반응성 회귀 표본·결과
- 보조 산출물: 합계출산율 추세, 청년층 정규직 근로자 비율 연도평균, QA 요약
- 제외: 반기 원자료 형태의 중간자료, 원천자료, 재정팀 검토용 Excel, 모델 checkpoint

## 갱신 기준

원자료, 라벨, CPI, 인구 또는 분석 정의가 변경될 때 해당 생성 노트북을 재실행하고, 결과 CSV와 QA 요약을 함께 갱신한다. 갱신 시 다음을 확인한다.

1. 기본 패널은 지역·연도 키를, 민감도 패널과 순위변동 후보는 지역·연도·분모대안 복합키를 확인한다.
2. 17개 시도 × 관측연도 행 수와 열 구성을 확인한다.
3. 결측·누락주의·음수 예산 등 QA 열을 확인한다.
4. 민감도·회귀 결과가 보고서의 입력 파일과 일치하는지 확인한다.
5. 개인 단위 정보나 민감정보가 포함되지 않았는지 확인한다.

## 현재 검증 결과

현재 추적 대상은 모두 시도·연도 집계 수준의 CSV이며 개인 식별정보를 포함하지 않는다. 핵심 패널은 17개 시도와 2016–2024년을 기준으로 점검했으며, 분석 목적상 허용된 결측은 QA 열과 `원자료_누락주의` 열로 표시한다.
