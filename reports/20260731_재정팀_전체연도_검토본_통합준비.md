# 재정팀 전체연도 검토본 통합 준비 결과

## 입력

- 재정팀 검토 중인 2016~2020·2022~2024년 검토본: 50,678건
- 2021년 17개 시도 수작업 라벨 원본: 7,301건
- 최신 지역별 정제 wide: 2016~2024년 57,979건
- #72 정제값 변경 영향표: 79건

입력 XLSX 원본은 `data/interim/영역분류_라벨링/재정팀_검토본/`에 보존하며
Git에는 포함하지 않는다.

## 통합 결과

최신 정제 wide를 기준으로 `연도·지역·원본행` 키를 사용해 57,979건을
통합했다.

- 전체 행: 57,979건
- 키 중복: 0건
- 2021년 행: 7,301건
- 2021년 라벨 결측: 0건
- 기존 로컬 2021 라벨 대비 재정팀 신규 라벨 변경: 106건
- #72 정제값 변경 표시: 79건
- 기존 검토 완료 행 중 #72 재확인 대상: 52건
- 기존 검토본 대비 최신 정제문 갱신: 78건

2021년은 수작업 라벨이 완료된 데이터이므로 `검토상태=확정`,
`라벨출처=2021 시도별 수작업 라벨`로 보존했다. 나머지 연도는 재정팀
검토본의 예측·검토 라벨·상태·메모를 그대로 이관했다.

## 유사 사업명 검토 순서

세부사업명을 NFC로 정규화하고 공백·문장부호를 제거한 뒤 문자 2~4그램
TF-IDF 최근접 유사도를 계산했다. 유사도 0.82 이상인 최근접 사업을 연결해
검토 그룹을 생성했다.

- 전체 유사사업 그룹: 17,458개
- 2건 이상 그룹: 11,342개
- 유사 그룹에 포함된 행: 51,863건
- 최대 그룹 크기: 388건
- 그룹 크기 중앙값: 2건
- 99백분위 그룹 크기: 21건

유사사업 그룹은 검토 순서를 제공할 뿐 라벨을 자동 변경하지 않는다.
동일·유사 사업명이라도 지역·시행 주체·사업 내용이 다를 수 있으므로 사람이
각 행의 최종 라벨을 판단한다.

## 로컬 산출물

`data/interim/영역분류_라벨링/재정팀_검토본/통합작업/`에 다음 CSV를
생성했다.

- `전체_57979건_원본순서.csv`
- `전체_57979건_유사사업명_검토용.csv`
- `2021_라벨변경_106건.csv`
- `통합_QA.csv`

데이터 산출물은 Git에서 제외하고, 재현 스크립트와 테스트 및 본 보고서만
추적한다.

## XLSX 내보내기

사용자 승인에 따라 `openpyxl` 대체 경로로 최종 검토용 XLSX를 생성했다.

- 파일: `2021포함_전체57979건_영역분류_검토.xlsx`
- `전체검토`: 57,979건, 기존 50,678건 검토 순서·라벨·상태·메모 보존
- `유사사업명검토`: 57,979건, 유사 그룹별 인접 정렬
- `통합QA`: 행 수·키·2021 라벨·#72 영향 검증
- `라벨목록`: 숨김 상태 유지
- 빈 `시트1`: 삭제

`전체검토` 시트에는 57,979행 전체 범위의 검토 세부영역·검토상태
드롭다운과 VLOOKUP 대영역 수식을 적용했다. 기존 규칙과 새 규칙의 중복을
제거하고, 저신뢰·수정·#72 재확인 행을 조건부 서식으로 구분했다.

재개방 검사에서 4개 시트, 전체검토 57,979건, 유사사업명검토 57,979건,
데이터 유효성 규칙 2개, 전체 범위 조건부 서식, 첫 행부터 마지막 행까지의
VLOOKUP 수식을 확인했다. macOS Quick Look 렌더링으로 헤더·본문·추가
영향 컬럼의 표시 상태도 확인했다.
