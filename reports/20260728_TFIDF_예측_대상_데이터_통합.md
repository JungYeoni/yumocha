# 2016~2020·2022~2024 TF-IDF 예측 대상 데이터 통합 결과

## 목적

2021년 수작업 라벨을 기준으로 영역분류를 예측할 나머지 8개 연도의
지역별 정제 데이터를 공통 스키마로 취합했다. 이 단계는 모델 학습이나
성능 평가가 아니라 TF-IDF `transform`·예측에 사용할 입력 데이터의
무결성을 확정하는 작업이다.

## 데이터 스냅샷

- 스냅샷 일자: 2026-07-28
- 입력 위치: `data/interim/{지역}/{연도}_{지역}_세부사업_정제.csv`
- 대상 연도: 2016~2020년, 2022~2024년
- 제외 연도: 2021년
- 대상 지역: 17개 시도
- 입력 파일: 136개
- 통합 행: 50,678행
- 공통 입력 스키마: 15개 열

연도별 행 수는 다음과 같다.

| 연도 | 행 수 | 주요내용_정제 결측 |
|---:|---:|---:|
| 2016 | 4,494 | 130 |
| 2017 | 4,551 | 25 |
| 2018 | 5,472 | 19 |
| 2019 | 6,484 | 29 |
| 2020 | 6,858 | 9 |
| 2022 | 8,122 | 8 |
| 2023 | 7,543 | 10 |
| 2024 | 7,154 | 133 |
| 합계 | 50,678 | 363 |

## 처리 및 검증

1. 8개 연도×17개 시도의 기대 파일 136개를 명시적으로 확인했다.
2. 모든 입력 파일에서 공통 15개 필수 열을 검증했다.
3. 파일 경로의 연도·지역과 파일 내부 값이 일치하는지 검증했다.
4. `연도+지역+원본행` 결측과 파일 내부·통합본 중복을 검사했다.
5. 2021년 행이 포함되지 않았는지 별도로 검증했다.
6. 136개 연도×지역 조합이 모두 존재하는지 확인했다.
7. `분류텍스트`는 2021년 학습본과 동일하게
   `세부사업명 + 주요내용_정제`를 NFC·공백 정규화하여 생성했다.

## 결측 처리

- `세부사업명` 결측: 0건
- `주요내용_정제` 결측: 363건
- `연도+지역+원본행` 결측: 0건
- `연도+지역+원본행` 중복: 0건
- 빈 `분류텍스트`: 0건

`주요내용_정제` 결측 행은 삭제하거나 임의 보완하지 않았다. 세부사업명이
모두 존재하므로 해당 행의 `분류텍스트`는 사업명만 사용하고,
`주요내용_정제_결측` 플래그를 남겼다. 주요내용 유사도는 후속 단계에서
이 363건을 계산 대상에서 제외해야 한다.

## 산출물

산출 위치는 `data/interim/영역분류_라벨링/TFIDF_분류대상/`이다.

- `2016_2020_2022_2024_TFIDF_분류대상_통합.csv`
- `2016_2020_2022_2024_TFIDF_분류대상.csv`
- `2016_2020_2022_2024_TFIDF_분류대상_QA.csv`

통합본은 원래 15개 열과 추적·결측·입력 텍스트 열을 모두 보존한다.
분류본은 `연도`, `지역`, `원본행`, `세부사업명`, `주요내용_정제`,
`분류텍스트`, `주요내용_정제_결측`, `원본파일` 8개 열만 포함한다.

`data/interim`은 Git 제외 대상이므로 산출 CSV 자체는 Git에 포함하지 않고,
생성 스크립트·노트북·테스트·보고서를 추적한다.

## 한계 및 잠재 편향

- 2021년 한 해의 라벨과 어휘가 다른 연도 사업을 충분히 대표하지 못할 수
  있다.
- 주요내용 결측 363건은 사업명에만 의존하므로 정보량이 더 적다.
- 원자료 정제 과정의 지역·연도별 누락과 표현 차이가 매칭률에 영향을 줄 수
  있다.
- 이 단계의 QA 통과는 영역분류의 정확도나 모델 일반화 성능을 의미하지
  않는다.
