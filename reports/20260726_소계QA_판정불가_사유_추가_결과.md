# [평가] 소계 QA 판정불가 사유 기록 — 2026-07-26

- 이슈: #31
- 대상: `src/features/pipeline_common.py`의 `build_subtotal_qa()` 및 `reports/yearly/{연도}/{연도}_전국_QA_검증결과.csv` (2016~2024, 9개 연도)

## 작업 배경

`build_subtotal_qa`는 원본 중분류 소계와 세부사업 합계를 대조할 수 없는 그룹을 `판정불가`로만 표시하고 구체적 원인을 남기지 않았다. 원인을 기계적으로 구분할 수 있도록 `판정불가_사유` 컬럼을 추가한다.

## 설계 결정

- **`판정불가_사유`는 `결과`뿐 아니라 `허용기준결과`가 `판정불가`인 경우도 포함한다.** "원본 소계가 0이라 오차율 계산 불가"는 나눗셈(오차율)에만 영향을 주고 `결과`(뺄셈 기반 일치/불일치)에는 영향을 주지 않아, `결과` 기준으로만 채우면 이 사유가 실제로는 채워지지 않는 문제가 있었다.
- **"원본 소계 중복·충돌"은 여전히 `ValueError`로 즉시 실패한다 (동작 변경 없음).** 같은 출처(중분류 제목 행 또는 별도 "소계" 행) 안에서 같은 그룹에 값이 다른 소계가 중복 추출되면 `collapse_consistent_subtotals`가 예외를 던지던 기존 동작을 그대로 유지했다. 이 예외가 `assign_qa_undetermined_reason()` 호출보다 먼저 발생하므로, 이 사유는 함수 반환값에 나타나지 않는 도달 불가능한 분기다 — 코드로 만들지 않고 docstring에만 명시했다.
- **"중분류 제목 행" vs "별도 소계 행" 값 불일치는 손대지 않았다.** 두 값이 다를 때 "별도 소계 행"을 조용히 우선 채택하는 동작은 `test_build_subtotal_qa_prefers_separate_subtotal_over_title_budget`가 의도된 설계로 이미 고정·테스트하고 있어 이번 이슈 범위 밖으로 판단했다.

## 실증 확인: "원본 소계 중복·충돌"의 실제 발생 여부

2016~2024년 136개 지역×연도 원본 파일(`data/interim/*/*_필터링전_전체원본.csv`)을 전수 스캔한 결과, **`build_subtotal_qa`가 실제로 사용하는 경로에서는 이 충돌이 한 번도 발생하지 않았다**:

| 충돌 유형 | 실제 발생 |
|---|---:|
| `중분류_소계`(제목 행) 내 값 충돌 — 전 연도 대상 | 0건 |
| "소계" 라벨 행 내 값 충돌 — 이 경로를 쓰는 2016·2019만 대상 | 0건 |

서울 2017년 원본에 동일 중분류에 대해 "소계" 라벨 행이 3개(값 상이) 존재하는 사례를 발견했지만, 전부 `사업행구분="헤더반복"`(페이지 반복 헤더, 필터링 대상)이고 2017년 노트북은 애초에 라벨 기반 소계 비교를 쓰지 않아 실제 파이프라인에는 영향이 없었다. 따라서 "원본 소계 중복·충돌"은 실제 발생 사유가 아니라 향후 이상 데이터 발생에 대비한 방어 조건으로 문서화했다(이슈 본문에도 반영).

## 결과

`scripts/annotate_subtotal_qa_reason.py`로 노트북 재실행 없이 기존 QA CSV에서 바로 사유를 계산해 반영했다 (CSV에 이미 `QA_병합상태`·`원본_소계값`·`leaf_합계`가 있어 재계산만으로 충분).

**연도별·사유별 건수:**

| 연도 | 검사행수 | 판정불가행수 | 원본 소계값 결측 | 세부사업 행 없음 | 원본 소계가 0이라 오차율 계산 불가 |
|---|---:|---:|---:|---:|---:|
| 2016 | 95 | 4 | 2 | - | 2 |
| 2017 | 95 | 93 | 91 | 2 | - |
| 2018 | 92 | 89 | 89 | - | - |
| 2019 | 98 | 8 | 8 | - | - |
| 2020 | 100 | 0 | - | - | - |
| 2021 | 133 | 0 | - | - | - |
| 2022 | 134 | 0 | - | - | - |
| 2023 | 135 | 0 | - | - | - |
| 2024 | 136 | 2 | - | 2 | - |

- "원본 소계값 결측"은 원본이 중분류 제목 행에 소계 숫자를 함께 적지 않은 연도(2017·2018·2019 일부, 2016 일부)에 집중된다 — 이슈 본문 예시(2017년 충북 사례)가 이 범주에 해당한다.
- "세부사업 행 없음", "원본 소계와 세부사업 합계 모두 결측"은 이번 스캔에서 발생하지 않았다.
- 2020~2023년은 `판정불가`가 전혀 없다(전 그룹이 `일치`/`불일치`로 확정 판정됨).

**검증:**
- 각 연도에서 `결과=="판정불가" 또는 허용기준결과=="판정불가"`인 행 집합과 `판정불가_사유`가 채워진 행 집합이 정확히 일치함을 스크립트 내부에서 교차 검증(불일치 시 `ValueError`) — 9개 연도 전부 통과.
- `git diff`로 CSV 변경 범위가 신규 컬럼 추가에 한정됨을 확인 (기존 `결과`/`허용기준결과`/`원본_소계값` 등 값 변경 없음).
- `uv run pytest -q` 158건 전체 통과, `uv run ruff check` 통과.

## 재현 방법

```bash
uv run pytest tests/test_pipeline_common.py -q
uv run python scripts/annotate_subtotal_qa_reason.py
```
