# TF-IDF 세부사업 영역분류 모델링 결과

## 1. 목적

2021년 17개 시도 세부사업 영역분류 정답 라벨을 이용해 TF-IDF 분류기를
학습하고, 2016~2020년 및 2022~2024년 정제 세부사업의 영역을 예측한다.
향후 신규 시행계획에도 동일한 전처리와 모델을 재사용할 수 있도록 학습
파이프라인과 모델 번들을 함께 저장한다.

## 2. 데이터

- 학습 파일: `2021_17개시도_TFIDF_학습데이터.csv`
- 학습 범위: 2021년 17개 시도 7,301행
- 예측 파일: `2016_2020_2022_2024_TFIDF_분류대상.csv`
- 예측 범위: 8개 연도·17개 시도 50,678행
- 목표 라벨: 세부영역 12종
- 학습 데이터 주요내용 결측: 17행
- 예측 데이터 주요내용 결측: 363행

주요내용이 결측인 행은 세부사업명만 사용한다. `지표체계 외`가 2,099행으로
가장 많고 `2-3. 가사수행 격차`는 23행에 불과하므로 정확도뿐 아니라
macro-F1과 클래스별 재현율을 함께 평가했다.

## 3. 방법

- 텍스트 표현: 문자 단위 TF-IDF, 2~5 gram, `min_df=2`
- 분류기: class weight를 보정한 로지스틱 회귀
- 입력 방식 비교:
  - 세부사업명
  - 세부사업명 + 주요내용 정제본
- 검증: 지역을 그룹으로 둔 5-fold `StratifiedGroupKFold`
- 모델 선택 기준: macro-F1, 동률이면 weighted-F1
- 난수 고정: 42

지역별로 반복되는 사업명과 서술이 임의 분할의 학습·검증 양쪽에 섞이는
것을 줄이기 위해 지역 단위로 fold를 분리했다. 모델은 최종 선택 후 전체
2021년 데이터로 다시 학습했다.

## 4. 평가 결과

| 입력 방식 | Accuracy | Macro-F1 | Weighted-F1 |
|---|---:|---:|---:|
| 사업명 + 주요내용 | 0.8628 | 0.8422 | 0.8648 |
| 사업명 | 0.8214 | 0.7782 | 0.8249 |

최종 입력 방식은 `사업명 + 주요내용`이다. 주요내용을 함께 사용하면
macro-F1이 0.0640 높아져, 사업명만으로 구분하기 어려운 영역의 문맥을
보완하는 효과가 확인됐다.

클래스별 F1은 `3-2. 산후조리 여건`이 0.9467로 가장 높고,
`2-2. 여가 인프라`가 0.6699로 가장 낮다. 표본이 23행뿐인
`2-3. 가사수행 격차`의 F1은 0.7317이지만 표본이 매우 작아 변동성이
크므로 결과 해석과 후속 수작업 검토에 주의해야 한다.

## 5. 8개년 예측 및 저신뢰 검토

최종 모델로 50,678행을 모두 예측했다. 예측 신뢰도 0.5 미만을 보수적인
검토 대상으로 두면 18,122행(35.8%)이다. 이는 전수 수작업 대상으로는
많으므로 목적에 따라 임계값을 조정할 수 있다.

| 임계값 | 예측 대상 검토 건수 | 비율 | 교차검증 오류 포착률 |
|---:|---:|---:|---:|
| 0.25 | 2,946 | 5.8% | 26.5% |
| 0.30 | 5,804 | 11.5% | 44.6% |
| 0.35 | 8,849 | 17.5% | 58.8% |
| 0.40 | 11,931 | 23.5% | 70.0% |
| 0.45 | 14,976 | 29.6% | 77.2% |
| 0.50 | 18,122 | 35.8% | 83.6% |

초기 수작업 검토는 0.30 미만 5,804건을 우선 검토하고, 검토 여력과 오류
유형에 따라 0.40 또는 0.50까지 확대하는 방식이 현실적이다. 신뢰도는
확률의 절대적 정확성을 보장하지 않으므로 자동 확정 기준으로 해석하지
않는다.

## 6. 산출물

실행 시 다음 로컬 산출물을 생성한다.

- 모델 비교표와 클래스별 평가표
- 입력 방식별 교차검증 예측과 혼동행렬
- 8개년 전체 예측
- 저신뢰 검토 대상
- 연도·지역별 예측 QA
- 전체 예측을 저신뢰 순으로 정렬한 영역분류 검토용 Excel
- 학습·예측 요약 JSON
- TF-IDF 벡터라이저와 분류기가 포함된 `joblib` 모델 번들

검토용 Excel의 `검토_세부영역`은 12개 taxonomy 드롭다운이며,
`검토_대영역`은 세부영역 선택값에 따라 자동 표시된다. `검토상태`는
미검토·확정·수정·보류 중 선택하고 검토메모를 남길 수 있다. 원래 모델
예측은 별도 열에 보존해 수정 전후를 비교할 수 있다.

데이터와 모델 파일은 `.gitignore` 대상이며 코드와 노트북으로 재생성한다.
신규 연도 데이터는 저장된 모델 번들을 이용해
`scripts/predict_tfidf_area_classifier.py`로 예측할 수 있다.

학습 스크립트는 학습·예측 입력 파일의 SHA-256과 실행 설정을 요약 JSON에
기록한다. 입력과 설정이 같고 모델·예측·검토 Excel이 모두 존재하면 기존
결과를 재사용하므로 노트북을 다시 실행해도 학습과 예측을 반복하지 않는다.
입력 변경 시에는 자동으로 다시 실행하며, 의도적으로 재학습할 때는
`force=True` 또는 CLI의 `--force`를 사용한다.

## 7. 한계와 잠재 편향

- 단일 연도인 2021년 라벨만 학습했으므로 다른 연도의 정책 용어 변화와
  신규 사업 유형에 대한 성능 저하가 발생할 수 있다.
- 지역 단위 교차검증은 지역 간 일반화 성능을 엄격하게 평가하지만,
  미래 연도 일반화 성능을 직접 검증하는 것은 아니다.
- 클래스 불균형과 일부 희소 라벨 때문에 macro-F1 및 소수 클래스 성능의
  변동성이 크다.
- 정답 라벨의 분류 판단 오류나 경계가 모호한 복합사업은 모델에 그대로
  학습된다.
- 저신뢰도만으로 모든 오분류를 찾을 수 없으므로, 라벨 분포 급변·연도별
  신규 용어·예산 규모가 큰 사업을 추가 QA 대상으로 검토할 필요가 있다.
