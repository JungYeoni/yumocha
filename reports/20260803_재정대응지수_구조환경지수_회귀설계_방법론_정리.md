# [Regression] 재정대응지수·구조환경지수 회귀 설계 방법론 정리 — 2026-08-03

- 관련 작업: 재정대응지수·재정반응성 분석(#62), 예산 연결 감사(#73), 구조환경지표 통합(#44), 결측 처리 민감도 분석(#70)
- 성격: 실제 회귀 실행 전 팀 내 방법론 합의를 위한 메모. 코드·데이터 산출물 없음.
- 배경: 팀원이 회귀식 설계 중 제기한 질문들을 실시간으로 전달받아 논의한 내용을 정리.

## 1. 목적

구조환경지수와 재정대응지수를 이용해 지방정부의 재정반응성, 재정 이후 구조환경 변화, 후속 출산 결과와의 관련성을 분석하는 과정에서 변수 정의·모형 구조·잠재적 통계 문제에 대한 팀 내 이해가 서로 달라 혼선이 있었다. 이 문서는 논의 과정에서 정리된 핵심 결론과 아직 풀리지 않은 쟁점을 기록해, 실제 회귀 실행 전 팀이 같은 전제를 공유하도록 한다.

### 1.1 기술 요약

- 두 지수를 한 식에 바로 넣기 전에 분석 질문을 **재정반응성**, **재정 이후 구조환경 변화**, **출산 결과와의 후속 관련성**으로 분리한다. 세 분석은 종속변수가 서로 다르다.
- #62의 1차 모형은 `재정대응지수`를 종속변수로 두고, 이전 출산동향과 이전 구조환경 수준에 지방정부 재정이 반응했는지를 검토한다. `TFR`을 종속변수로 두는 식은 후속 결과모형이다.
- 세부영역 지수는 같은 대영역에 속한다는 이유만으로 투입이 금지되지는 않지만, 공통 산식·정책 우선순위·지역 추세 때문에 공선성이 높을 수 있다. 최종 `시도×연도` 패널에서 pooled 상관, within 상관, 시도·연도 효과 제거 후 잔차 상관, VIF를 순서대로 확인한다.
- 최대 표본은 17개 시도×9개년=153개이고 1년 시차 적용 시 최대 136개로 줄어든다. 결측까지 고려하면 모든 세부영역과 통제변수를 한꺼번에 넣는 모형은 과적합·불안정 위험이 크므로 대영역 모형을 주 분석으로, 세부영역 모형은 영역별 진단과 강건성 분석으로 둔다.
- 분석 실행 전 사람 확정 라벨, #73 예산 연결 감사, 보간 전 구조환경 28개 패널, #70 결측 처리 방침을 먼저 확정해야 한다.

## 2. 배경: 재정대응지수의 세 가지 변형

| 변형 | 정의 | 비고 |
|---|---|---|
| 전체예산 기준 | 세부영역 구분 없이 저출생 대응 예산 전체를 합산 | 기존에 구축된 지수 |
| 세부영역대응 | 대영역 하위 세부영역(11개)별로 각각 산출 | 이번 논의의 주 대상 |
| 세부지표대응 | 세부영역 값을 그 영역에 속한 개별 세부지표에 그대로 broadcast | 세부영역대응과 값 자체는 동일, 결합 단위만 다름 |

기본 산출 후보는 `명목예산 → CPI 실질화 → 인구당 표준화 → log1p → z-score`다. 인구 분모를 전체 인구로 할지 정책대상인 20~39세 인구로 할지는 아직 확정하지 않고 두 계열을 비교한다. 전체 저출생 대응 규모를 설명하는 표에는 전체 인구 1인당 값을, 대상집단 대비 정책집중도를 보는 민감도 분석에는 20~39세 인구당 값을 우선 검토한다.

## 3. 핵심 결론

### 3.1 종속변수(Y)는 분석 질문별로 달라진다

종속변수를 하나로 고정하기보다 분석을 다음 세 단계로 구분한다.

#### A. 1차 분석: 재정반응성

```text
F_it = φ·ΔTFR_i,t-1 + γ·S_i,t-1 + α_i + λ_t + ε_it
```

- `F_it`: t년 재정대응지수
- `ΔTFR_i,t-1`: 이전 연도의 합계출산율 변화
- `S_i,t-1`: 재정투입 이전 구조환경 수준
- `α_i`, `λ_t`: 시도·연도 고정효과

이 식의 질문은 “출산율이 악화되거나 구조환경이 취약했던 지역이 다음 연도에 예산을 더 늘렸는가?”이다. 낮은 출산율 때문에 예산이 늘어나는 역인과성을 오류로 제거하는 것이 아니라, 지방정부의 **반응 관계 자체**를 분석한다.

#### B. 2차 분석: 재정 이후 구조환경 변화

```text
S_it = ρ·S_i,t-1 + γ·F_i,t-1 + α_i + λ_t + ε_it
```

이 식은 이전 재정대응이 이후 구조환경 변화와 관련되는지를 본다. 재정지출이 출산율보다 고용·주거·돌봄 등 중간 환경에 먼저 영향을 준다는 정책 경로에 더 가깝다.

#### C. 후속 분석: 출산 결과와의 관련성

```text
TFR_it = β·S_i,t-1 + γ·F_i,t-1 + δ'X_i,t-1 + α_i + λ_t + ε_it
```

이 단계에서만 `TFR`을 종속변수로 둔다. 최초 검토했던 `Y=출생아수` 식은 지역별 인구 규모를 직접 반영해 지역 간 비교가 왜곡될 수 있으므로 주 분석에서 제외한다. 다만 이 모형도 관찰자료의 조건부·시차적 관련성을 보여줄 뿐 재정투입의 인과효과를 자동으로 식별하지는 않는다.

### 3.2 재정대응지수 회귀식에서 b(계수)와 변수 역할의 구분

논의 중 "b1이 영역예산총액/시도인구의 합이 되는 게 맞냐"는 질문이 나왔는데, 이는 **β(계수)와 X(변수)를 혼동**한 것이었다.

- **재정대응지수**: 영역예산총액을 인구당·실질화·표준화한 관측변수다. 재정반응성 모형에서는 종속변수 `F`, 구조환경·TFR 후속 모형에서는 독립변수 `X` 역할을 한다.
- **영역예산총액/시도인구**: 재정대응지수를 만드는 산식이며 회귀계수가 아니다.
- **β(계수, 회귀식의 b)**: 회귀분석이 추정하는 값으로, X가 한 단위 오를 때 Y가 얼마나 변하는지를 나타낸다. 사람이 미리 계산해서 넣는 값이 아니다.

이 구분이 안 되면 "b1을 어떻게 정의할지"를 회귀 전에 결정하려는 오류가 생긴다. b(β)는 회귀 실행 결과로 나오는 것이고, 우리가 미리 설계하는 건 X(재정대응지수 산출 방식)다.

### 3.3 같은 대영역 내 세부영역을 동시에 독립변수로 넣을 때의 다중공선성

같은 대영역에 속했다는 사실만으로 세부영역들을 한 회귀식에 넣을 수 없는 것은 아니다. 다만 세부영역대응 지수를 동시에 쓸 때, 같은 대영역에 속한 세부영역들(예: 경제·고용·주거 아래 고용여건/주거 안정성/경제적 여건) 사이에 **다중공선성(multicollinearity)**이 생길 가능성이 크다.

- 같은 대영역의 세부영역들은 지자체의 재정여력·정책 우선순위에서 함께 움직이는 경향이 있어 상관관계가 높기 쉽다.
- 대영역 예산총액이 세부영역 예산의 합이라면, 세부영역 전체 + 대영역을 같이 넣는 것은 산술적으로 완전공선성이 된다.
- 변수를 z-score로 표준화해도 단위만 바뀔 뿐 변수 간 상관과 공선성은 사라지지 않는다.
- 대영역별로 회귀를 나누면 전체 11개 세부영역을 한꺼번에 넣는 것보다 부담이 줄지만, 같은 대영역 내부의 공선성까지 자동으로 사라지는 것은 아니다.

#### 상관과 공선성을 확인하는 관측 단위

상관은 세부사업 행 단위가 아니라 최종 회귀와 동일한 `시도×연도` 행에서 본다.

| 시도 | 연도 | 고용여건 | 주거안정성 | 경제적여건 | 돌봄여건 | … |
|---|---:|---:|---:|---:|---:|---:|
| 서울 | 2016 | 값 | 값 | 값 | 값 | … |
| 서울 | 2017 | 값 | 값 | 값 | 값 | … |
| 부산 | 2016 | 값 | 값 | 값 | 값 | … |

최종 회귀에서 1년 시차 변수를 사용하면 상관과 VIF도 같은 시차·결측 제거 후 분석 표본에서 다시 계산한다.

#### 권장 진단 순서

1. **pooled Pearson 상관**: 17개 시도×연도 전체에서 선형 상관 확인
2. **pooled Spearman 상관**: 극단치와 비선형 단조관계에 덜 민감한 순위상관 확인
3. **within 상관**: 각 지표에서 시도별 평균을 빼고, 같은 시도 내부의 연도별 변화가 함께 움직이는지 확인
4. **시도·연도 고정효과 잔차 상관**: 각 지표에서 시도 고정효과와 연도 고정효과를 제거한 잔차끼리 상관 계산
5. **VIF와 조건수**: 실제 회귀에 투입할 독립변수 행렬 전체의 공선성 확인
6. **계수 안정성**: 상관이 높은 세부영역을 하나씩 제외했을 때 계수 부호·크기·신뢰구간이 유지되는지 비교

`|r|≥0.7`은 강한 상관을 의심하는 참고 신호로, `VIF≥5`는 주의, `VIF≥10`은 심한 공선성 가능성으로 기록한다. 이는 기계적인 변수 탈락 기준이 아니며 이론적 필요성, 표본 수, 계수 안정성을 함께 판단한다. 모든 상관표에는 변수쌍별 실제 관측치 수를 표시해 결측 패턴이 다른 상관계수가 동일한 근거처럼 보이지 않게 한다.

높은 상관이 나오면 실제 현상뿐 아니라 지수 산식도 확인한다. 같은 원지표 중복, 공통 분모, 동일한 보간값, AHP 가중치 중복, 대영역 값의 세부영역 재사용은 기계적인 상관을 만들 수 있다.

### 3.4 세부영역 예산을 전체 합산해서 쓸 경우의 회귀식과 트레이드오프

다중공선성을 피하기 위한 대안으로 세부영역 예산 전체를 합산해 단일 변수로 쓰는 방안도 검토했다.

```
Y_it = β0 + β1 × 재정대응지수_전체_it + Σβk × 통제변수_kit + 지역고정효과_i + 연도고정효과_t + ε_it
```

- 세부영역들끼리 생기는 공선성은 사라진다. 다만 전체 재정대응지수와 통제변수·구조환경지수 사이의 공선성은 여전히 확인해야 한다.
- 대신 **"어느 세부영역이 효과가 있었는지"는 이 식으로는 알 수 없다.** 세부영역 간 효과 차이가 합산 과정에서 뭉개진다.
- **선택 기준**: "어느 세부영역과 결과가 관련되는지" 알고 싶으면 영역별 세부모형을 사용하고, "재정대응 규모 자체"만 보면 되면 전체 합산이 더 간단하고 안정적이다. 관찰자료 회귀만으로 특정 세부영역의 인과적 "효과"를 확정하지 않는다.

권장 모형 순서는 다음과 같다.

1. 전체 재정대응지수 1개를 사용한 기준모형
2. 대영역 지수를 사용한 주 분석모형
3. 대영역별로 해당 세부영역만 넣는 진단모형
4. 전체 세부영역 동시 투입은 공선성·표본 수를 확인한 강건성 분석
5. 공선성이 심하면 대영역 합성지수, PCA 또는 Ridge를 예측·민감도 분석으로 비교하되 계수의 정책 해석과 분리

### 3.5 AHP 세부지표 가중치 확정

제주여성가족연구원(2025) 원 가중치표(엔트로피·AHP·최종 3계열, 31개 지표)를 직접 합산해 글로벌 가중치임을 검증했다. 이후 팀에서 미구축 지표를 제외해 재정규화한 28개 지표 가중치표(`data/lookup/구조환경지표_AHP가중치_3방식.xlsx`)를 받았고, **#82에서 지수 산출에 `AHP` 탭만 쓰기로 확정**했다(엔트로피·최종 결합 계열은 사용하지 않음). 최초 이 절에는 "최종(엔트로피+AHP 평균) 계열을 쓴다"고 적었으나, 이는 담당자 확인 없이 임의로 고른 기본값이었고 #82의 명시적 결정과 어긋나 AHP 계열 기준으로 정정한다.

- **글로벌 가중치임을 확인**: 원표 전체 31개 지표의 `최종` 가중치 합은 1.007, `AHP` 합은 0.998, `엔트로피` 합은 1.002로 모두 1에 근접했다(반올림 오차 범위). 로컬 가중치라면 세부영역 내부에서만 합이 1이어야 하는데 그렇지 않았다. 세부지표 → 세부영역 → 대영역 순으로 합산한 값도 정확히 일치했다. **세부지표 가중치의 단순 합이 세부영역·대영역 가중치가 된다는 전제는 성립한다.**
- **사용 계열**: `AHP` 탭(전문가 판단 기반 가중치)만 쓴다. 엔트로피·최종(결합) 계열은 #82에서 사용하지 않기로 확정했다.

### 3.6 통제변수 후보

지역고정효과·연도고정효과가 각각 시간불변 지역 특성과 전국 공통 연도 충격을 흡수하므로, 통제변수는 **같은 지역 안에서 연도별로 변하면서 해당 종속변수에도 영향을 주는 변수** 중 구조환경지수와 겹치지 않는 것으로 골라야 한다. 모든 후보를 모든 모형에 자동으로 넣지 않고 재정반응성·구조환경 변화·TFR 결과모형별 인과 순서를 먼저 그린 뒤 결정한다.

| 변수 | 선정 이유 |
|---|---|
| 조혼인율 또는 평균초혼연령 | 한국은 혼인 내 출산 비중이 압도적으로 커서 출산율의 직접적 선행요인 |
| 가임기여성 비율(20-39세 인구 비중) | 분모 구성 자체가 출산율 수치에 기계적으로 영향 |
| 1인당 지역총생산(GRDP) | 재정 지출과는 별개인 지역의 전반적 경제 수준 |
| 순이동률(전입-전출) | 인구 유출입이 출산율 통계를 왜곡할 수 있음 |

**주의**: 구조환경지수에 이미 포함된 항목(주택가격, 고용률, 보육시설 보급률 등)을 통제변수로 다시 넣으면 이중계산·공선성 문제가 생기므로 제외한다.

조혼인율·평균초혼연령·순이동률은 재정 또는 구조환경이 출산 결과에 영향을 주는 경로의 중간변수일 수도 있다. TFR 결과모형에서 이를 통제하면 총 관련성의 일부를 제거하는 `bad control`이 될 수 있으므로, 기본모형과 추가 통제모형을 분리해 계수 변화를 제시한다.

### 3.7 선행연구(생애주기별 정책분류 연구) 대비 우리 방법론의 차별점

참고 선행연구는 두 가지 한계를 스스로 밝히고 있다.

1. 정책사업을 생애주기별로 분류하는 과정에 연구자 주관이 개입 → 전문가 검증·데이터 기반 분류기법 필요.
2. 통제변수를 회귀에 직접 못 넣어, 사회경제적 변수 기준 군집분석으로 대체 → 군집분석은 유사 집단 층화에 그쳐 통제변수 직접 투입을 완전히 대체하지 못함.

우리 프로젝트와 대응 관계:
- (1)은 TF-IDF 영역분류(#77)·유사사업 그룹핑(#65)이 데이터 기반 분류 + 사람 검토로 개선하려는 지점과 일치한다.
- (2)는 우리와 무관하다. `similarity_grouping.py`의 군집은 지역을 사회경제적 변수로 묶는 게 아니라 세부사업명 텍스트 유사도로 묶는 것으로, 목적 자체가 다르다(분류 라벨링 보조용). 우리 회귀 설계는 애초에 통제변수·고정효과를 회귀식에 직접 반영하는 방식이라, 이 선행연구가 "후속 연구 과제"로 남긴 개선 방향을 이미 채택하고 있다.

### 3.8 구조환경 취약도 산식과 재정대응 2×2 분류

최종 결과표에서 `구조환경 취약도`와 `재정대응`을 높음/낮음으로 나눠 정책 우선순위를 제시하려면, 취약도를 구조환경지수와 별개로 임의 생성하지 않고 **방향을 통일한 구조환경지수의 반대 방향**으로 정의한다.

#### 원지표에서 구조환경지수를 만드는 경우

세부지표 `j`에 대해 값이 높을수록 환경이 좋으면 `d_j=+1`, 나쁘면 `d_j=-1`로 두고 다음과 같이 방향을 통일한다.

```text
Z*_jit = d_j × (X_jit - 기준평균_j) / 기준표준편차_j
S_kit  = Σ_j∈k w_j × Z*_jit
V_kit  = -S_kit
```

- `S_kit`: 세부영역 `k`의 구조환경지수. 값이 높을수록 양호
- `V_kit`: 같은 영역의 구조환경 취약도. 값이 높을수록 취약
- `w_j`: AHP 가중치. 결측 지표 제외 시 재정규화 원칙을 사전에 확정

이미 구조환경지수가 z-score로 완성돼 있다면 `취약도=-구조환경지수`만 적용한다. 표시용 구조환경점수가 0~100이고 높을수록 양호하다면 `취약도=100-구조환경점수`로 표시할 수 있다. 회귀에는 연속형 z-score를 사용하고, 0~100 점수와 높음/낮음 분류는 설명·시각화용으로 분리한다.

예를 들어 구조환경 z-score가 `-0.8`이면 취약도는 `+0.8`이고, 구조환경 표시점수가 `65점`이면 취약도 표시점수는 `35점`이다. 두 값은 표현 단위만 다르며 모두 구조환경이 낮을수록 취약도가 높아지게 만든다.

#### 높음/낮음 기준

2×2 표의 절단점은 결과를 본 뒤 임의로 정하지 않고 사전에 고정한다.

- **연도별 정책 우선순위 표**: 해당 연도 17개 시도의 중앙값을 기본 절단점으로 사용
- **2016~2024 전체 비교**: 전체 시도×연도 pooled z-score의 `0`을 기본 절단점으로 사용
- **민감도 분석**: 중앙값, 상·하위 1/3, pooled z-score 0 기준에서 분류가 얼마나 바뀌는지 비교

시도 17개뿐이므로 사분위수로 네 등급을 지나치게 세분화하기보다 중앙값 기준 2분류를 기본으로 한다. 중앙값과 정확히 같은 값의 처리 규칙(`높음` 포함 여부)도 코드에서 고정한다.

| 구조환경 취약도 | 재정대응 | 해석 |
|---|---|---|
| 높음 | 높음 | 취약성이 높고 상대적으로 적극 대응 중 |
| 높음 | 낮음 | 정책 우선순위 지역: 취약성 대비 대응 부족 가능성 |
| 낮음 | 높음 | 선제투자·유지투자 또는 과잉배분 여부 추가 검토 |
| 낮음 | 낮음 | 현재 상대적 우선순위가 낮음 |

이 표는 지역의 **상대적 위치를 기술하는 분류**다. `높은 재정대응 → 구조환경 개선`의 인과효과나 예산의 적정성을 증명하지 않는다. 특히 `취약도 낮음·재정대응 높음`은 과잉배분으로 자동 판정하지 않고, 선제투자·사업 지속성·전국 공통정책 여부를 확인한다.

#### 영역 대응 원칙

- 전체 취약도는 전체 재정대응지수와 비교한다.
- 고용여건 취약도는 고용여건 재정대응지수처럼 동일한 영역끼리 비교한다.
- 세부영역 재정값을 소속 세부지표마다 반복한 `세부지표대응`은 표시·결합 편의를 위한 값이며 독립적인 재정 관측치로 해석하지 않는다.
- 복합대응예산은 영역별 재정대응에서는 제외하고, 시도별 인구 1인당 전체 대응예산에는 포함한다. 2×2 표에도 사용한 포함·제외 기준을 주석으로 명시한다.

### 3.9 패널 표본과 추정 순서

분석기간이 2016~2024년이면 최대 표본은 153개 지역·연도다. 1년 시차를 사용하면 최대 136개이며, 구조환경지표의 조사연도 결측과 통제변수 결측이 추가되면 실제 표본은 더 작아진다. 따라서 변수 수를 늘리는 것보다 같은 표본에서 모형을 단계적으로 비교하는 것이 중요하다.

1. 기술통계와 2×2 상대위치 분류
2. 전체 재정대응지수 기준모형
3. 대영역별 재정반응성 모형
4. 세부영역별 대응관계 진단
5. 재정 이후 구조환경 변화 모형
6. TFR 결과모형과 상호작용항은 후속·탐색 분석

모든 고정효과 모형은 지역 단위 군집표준오차를 기본으로 검토하되, 군집 수가 17개로 적다는 한계를 명시하고 필요하면 wild cluster bootstrap 등 소표본 강건성 검정을 추가한다. 서로 다른 결측 처리 방식에서 표본 자체가 달라지면 계수 차이가 대체 방식 때문인지 표본 구성 때문인지 구분할 수 있도록 공통 완전사례 표본 결과도 함께 제시한다.

## 6. 해석 및 보고 원칙

- 2×2 표는 정책 우선순위를 탐색하는 상대적 분류이며 회귀의 대체물이 아니다.
- 회귀계수는 조건부·시차적 관련성으로 표현하고, 별도의 식별전략 없이 인과효과로 단정하지 않는다.
- 영역별 결과에는 복합대응예산 제외, 전체 대응예산에는 복합대응예산 포함 여부를 주석으로 명시한다.
- 각 모형 표에 종속변수, 지수 산식, 인구 분모, 표준화 기준, 시차, 고정효과, 군집표준오차, 실제 표본 수와 결측 처리 방식을 함께 기록한다.
- 주 분석과 민감도 분석의 표본이 달라질 경우 공통 완전사례 표본 결과를 추가해 표본 변화와 산식 변화의 영향을 구분한다.
- 세부영역 결과는 대영역 결과와 방향이 다르거나 계수가 불안정하면 선택적으로 강조하지 않고 전체 진단표와 함께 보고한다.
