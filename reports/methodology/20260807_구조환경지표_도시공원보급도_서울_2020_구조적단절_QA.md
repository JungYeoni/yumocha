# 구조환경지표 "도시공원 보급도" — 서울 2020년 구조적 단절 QA — 2026-08-07

## 배경

이슈 #63(구조환경지표 신규 구축값 시각화 반영) 작업 중 지역별 데이터를 다시 훑어보다가, "도시공원 보급도"(project_code 2-2.2) 지표에서 2019→2020년 사이 다수 지역이 40~100% 급등한 반면 **서울만 유일하게 반대 방향(거의 반토막)** 으로 움직인 패턴을 발견했다.

## 원자료 확인

`data/raw/지표별_측정값/2-2.2. 도시공원 보급도.xlsx` 직접 대조 결과:

| 지역 | 2019 | 2020 | 변화 |
|---|---:|---:|---:|
| **서울** | **8.4** | **4.4** | **-47.6%** |
| 인천 | 10.8 | 12.9 | +19.4% |
| 광주 | 6.9 | 12.2 | +76.8% |
| 전북 | 14.1 | 24.4 | +73.0% |
| 제주 | 6.0 | 12.0 | +100.0% |
| 경기 | 9.6 | 10.0 | +4.2% |

서울 시계열(2016~2024): 8.0 → 8.1 → 8.3 → 8.4 → **4.4** → 4.6 → 4.7 → 4.6 → 4.7. 2020년 한 번 계단식으로 꺾인 뒤 그 레벨에서 안정화됐다 — 일시적 노이즈가 아니라 영구적 레벨 이동이다.

## 기존 급등락 탐지 로직이 이 사례를 놓친 이유

`src/features/trend_eda.py`의 `_add_iqr_outlier_flag()`는 같은 해 17개 시도의 전년대비변화 분포에서 IQR(사분위범위) 기준으로 이상치를 잡는다. 2020년 데이터로 이 로직을 직접 재현한 결과:

- Q1=0.0, Q3=3.8, IQR=3.8 → 하한 -5.7, 상한 9.5
- 서울의 변화량(-4.0)은 하한(-5.7)보다 크므로 **이상치로 잡히지 않음**
- 같은 해 다수 지역이 동시에 상승한 탓에 분포 자체가 위로 넓게 벌어졌고, 그 결과 하한선도 같이 낮아지며 서울의 하락이 "정상 범위"로 통계적 착시를 일으킴
- 기존 `reports/20260724_구조환경지표_21개_검증_진행상황.md`는 이 지표의 "급등락, 원인 미상"을 이미 플래그했지만, 서울이 유일하게 반대 방향이라는 구체적 패턴은 문서화돼 있지 않았다

## 결론

> 2020년 도시공원 일몰제 시행과 서울시의 대규모 도시관리계획 변경으로 종전 도시계획시설 공원 가운데 상당 부분이 도시자연공원구역·국립공원 등 별도 법정 범주로 재분류되었다. 이 과정에서 「도시계획현황」상 도시공원 조성면적의 집계 범위가 크게 축소되어 서울 지표가 8.4에서 4.4로 하락한 것으로 판단된다. 이는 실제 녹지나 시민 이용 가능 면적이 절반 감소했다는 뜻이 아니라, 주로 법적 분류·통계 집계범위 변화에 따른 구조적 단절이다.

## 한계

- 국가데이터처 경인지방통계청 각주 원문을 스캔 PDF에서 직접 재확인하지 못했다(도구 한계, OCR 실패). 반박 근거는 없어 그대로 수용한다.
- "조성면적은 원래 미집행면적을 제외한다"는 정의를 그대로 적용하면, 미집행 지정이 해제됐다고 조성면적(이미 미집행분을 뺀 값)이 자동으로 줄어야 할 산술적 이유는 명확하지 않다. 즉 **정확한 통계 집계 메커니즘(왜 조성면적까지 줄었는지)은 완전히 규명되지 않았다** — 도시자연공원구역 전환 과정에서 이미 조성된(개발된) 구간 일부까지 "도시공원" 범주에서 함께 빠졌을 가능성이 유력하지만, 이는 국토교통부 「도시계획현황」 원자료를 직접 대조해야 확정할 수 있다.
- KOSIS 원자료 화면은 SSO 로그인 장벽으로 직접 열람하지 못했다.
