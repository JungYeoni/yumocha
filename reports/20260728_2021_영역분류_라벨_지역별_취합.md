# 2021년 영역분류 라벨 지역별 취합 결과

## 목적

2021년 17개 시도별 수작업 영역분류 라벨을 하나의 기준 데이터로 취합하여
향후 TF-IDF 분류기의 학습 데이터로 사용할 수 있도록 스키마와 taxonomy를
검증했다.

## 입력 데이터

- 위치: `data/interim/영역분류_라벨링/2021/`
- 파일: 지역별 XLSX 17개
- 기간: 2021년
- 지역: 17개 시도
- 총 행 수: 7,301행
- 데이터 스냅샷: 2026-07-28 지역별 완료 XLSX 17개
- 원자료 대조본: 2026-07-28 기준 지역별 `2021_{지역}_세부사업_정제.csv`

지역별 행 수는 서울 228, 부산 685, 대구 267, 인천 367, 광주 195, 대전 294,
울산 249, 세종 93, 경기 1,149, 강원 437, 충북 438, 충남 624, 전북 473,
전남 524, 경북 439, 경남 684, 제주 155행이다.

## 재현 및 평가 메타데이터

- 분석 범위: 데이터 통합 및 QA
- 모델 학습·평가: 미수행
- 데이터 분할 전략: N/A
- 평가 지표: N/A
- CV fold 수: N/A

이번 결과의 중복·결측·원자료 키 대조는 모델 성능 평가가 아니다. TF-IDF
모델의 분할 전략과 평가 지표는 후속 모델링 단계에서 별도로 정의한다.

## 처리 및 검증

1. 파일명과 파일 내부 `지역` 값이 일치하는지 확인했다.
2. 모든 파일의 필수 17개 열을 검증했다. 울산 파일에만 있는 검토 상태 열은
   공통 학습 스키마에 포함하지 않았다.
3. `지역+원본행`을 원자료 연결 키로 사용했으며 중복은 0건이었다.
4. 각 지역의 정제 원본 CSV와 키를 대조한 결과 누락·추가 행은 모두 0건이었다.
5. `세부영역` 12종을 기준으로 `대영역`을 정규화했다.
6. TF-IDF 입력용 `분류텍스트`는 `세부사업명 + 주요내용_정제`로 만들었다.
   `주요내용_정제`가 비어 있으면 세부사업명만 사용한다.

## Taxonomy 정규화

정규화 대상은 총 261건이다.

- 255건: 기존 `4. 사회·제도`를 현행 기준인 `4. 사회·문화`로 통일
- 6건: 세부영역과 대영역이 직접 충돌하거나 대영역이 비어 있던 사례
  - 대전 3건
  - 전북 1건
  - 충북 2건

정규화 전 값은 `대영역_원본`에 보존하고, 변경 여부는
`taxonomy_정규화여부`에 기록했다. 따라서 자동 정규화 이후에도 원래
수작업 라벨을 추적할 수 있다.

## 결측 및 중복

- `대영역` 원본 결측: 1건
- `주요내용_정제` 결측: 17건
- `세부사업명` 결측: 0건
- 정규화 후 대영역·세부영역 결측: 0건
- `지역+원본행` 중복: 0건

`주요내용_정제` 결측 17건은 세부사업명이 존재하므로 제거하지 않았다.
학습 시 텍스트 정보가 상대적으로 적은 행임을 확인할 수 있도록
`주요내용_정제_결측` 플래그를 남겼다.

## 산출물

산출물은 `data/interim/영역분류_라벨링/2021/통합/`에 생성된다.

- `2021_17개시도_영역분류_라벨_통합.csv`

- `2021_영역분류_taxonomy_정규화_상세.csv`

`data/interim`은 Git 추적 대상이 아니므로 산출물은 로컬 데이터로 관리하고,
재생성 코드는 `scripts/consolidate_2021_area_labels.py`와 분석 노트북에
남긴다.

## 학습·예측 단계의 원칙

TF-IDF 벡터라이저와 분류기는 정답 라벨이 있는 2021년 데이터에만 `fit`한다.
2016~2020년과 2022~2024년 자료는 동일 스키마로 합친 뒤 학습된
벡터라이저로 `transform`하여 예측한다. 라벨이 없는 연도까지 TF-IDF
어휘집 학습에 포함하지 않아 데이터 누수를 방지한다.

현재 단계에서는 모델 학습·평가를 수행하지 않았으므로 데이터 분할 전략,
평가 지표 및 CV fold 수는 모두 N/A이다.

## 한계

- 세부영역을 기준으로 대영역을 정규화했으므로 6건의 직접 충돌은 원래
  대영역보다 세부영역 라벨이 더 신뢰할 만하다는 가정을 사용한다.
- 2021년 한 해의 문구와 사업 구성이 다른 연도를 충분히 대표하지 못할 수
  있다. 연도별 저신뢰 예측과 미등록 어휘 비율을 별도로 점검해야 한다.
- 수작업 라벨 자체의 분류자 간 일치도는 이번 취합 범위에서 재측정하지
  않았다.
